### 🚀 Featured Project

### 🏠 House Price Prediction System

An end-to-end Machine Learning application that predicts residential property prices through an interactive web dashboard.

**Key Highlights**

- Built a predictive model using **Extra Trees Regressor (300 estimators)**.
- Implemented data preprocessing, feature engineering, IQR-based outlier removal, and One-Hot Encoding.
- Developed reusable Machine Learning pipelines using Scikit-learn.
- Evaluated model performance using MAE, MSE, RMSE, and R².
- Built a REST API using FastAPI.
- Developed an interactive dashboard using Streamlit and Plotly.
- Hosted the trained model on Hugging Face Hub.
- Deployed the backend on Render and frontend on Streamlit Community Cloud.

**Model Performance**

| Metric | Result |
|---|---:|
| MAE | 77,106.38 |
| RMSE | 119,584.35 |
| R² Score | 0.7114 |
