## 🚀 Projects

### 🏠 House Price Prediction

**Technologies:** Python | Pandas | NumPy | Scikit-learn | Random Forest

- Built an end-to-end house-price prediction system using a Random Forest Regressor with 200 estimators.
- Engineered date-based features to improve the model's input representation.
- Removed outliers using the Interquartile Range (IQR) method.
- Imputed missing values and encoded categorical variables using One-Hot Encoding.
- Created a Scikit-learn Pipeline and ColumnTransformer to integrate preprocessing with model training and ensure consistent data transformation.
- Evaluated model performance using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R-squared.
- Serialized the trained model using Pickle and Joblib for reuse and deployment.
